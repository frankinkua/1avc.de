# 1A VC (1avc.de)

Category: brands-misc

## Concept
A founder's field guide to venture capital in Germany: how a funding round works (pre-seed to Series A), a glossary, a cap-table dilution calculator that runs in the browser, and a checklist for preparing a pitch. Educational, not an investment offer.

## Look
Serious and sharp: near-black navy, white and a single electric-blue accent, large editorial serif headlines with a mono font for numbers.

## Architecture & Structure
This is a purely static website with no build step or external dependencies. It uses plain HTML, CSS, and vanilla JavaScript and is designed to be served directly from the repository root by GitHub Pages.

### File Structure:
- `index.html`: The main one-page landing site including the Cap-Table-Rechner.
- `style.css`: All styling, including responsive design and dark mode support.
- `script.js`: The logic for the Cap-Table-Rechner.
- `impressum.html`: Imprint page.
- `datenschutz.html`: Privacy policy.
- `404.html`: Custom 404 error page.
- `favicon.svg`: Vector icon used as the favicon.
- `robots.txt` & `sitemap.xml`: SEO setup.
- `CNAME`: Configures the custom domain for GitHub Pages.
